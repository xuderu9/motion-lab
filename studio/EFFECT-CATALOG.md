## 状态口径（四个词，不许混用）

| 状态 | 含义 | 判定方式 |
|---|---|---|
| **已落地** live | 成片里真的会被渲染出来 | 源码有符号 + 调用点可追 |
| **近似** partial | 做了，但和术语描述有差距 | `note` 里必须写清差在哪 |
| **已写未接** ready | 函数写好了，但还没有版面调用它 | 只算「零件进库」，不算落地 |
| **未做** planned | 没做 | — |
| **不适用** na | 视频里没有这个概念（鼠标/滚动/呼吸） | — |

`ready` 单独统计，就是为了防止再把「我写了函数」当成「我做了效果」。

## 已经改掉的三个「假落地」

1. **卡片精致度**：`cardBg` 原来是「一层平涂 + 一条 1px 描边」。现在是 7 层：
   环境投影 / 接触投影 / 受光面渐变 / 顶部内高光 / 底部内阴影 / 双层描边 / 静态纸噪点。
2. **运动轨迹**：所有入场位移从 `(1-p)*h*0.026`（一条直线）改成
   `motion.ts` 的贝塞尔路径 + CSS 语义缓动 + 错峰 + 速度触发运动模糊。
3. **静止帧**：`paperBg` 的横纹、`panel` 的点阵原来都在「缓慢漂移」凑帧差。已全部改成静态 ——
   那不是动效，那是用户明令禁止的呼吸感。
